# PLAYDROP — своя площадка браузерных игр

Каталог + плеер в iframe + SDK, совместимый с Yandex Games SDK. Игры, написанные под `ysdk`, работают без правок.

## Структура

```
index.html            каталог + полка «Продолжить»
admin.html            панель загрузки игр (только для админов)
profile.html          профиль: уровень, серия дней, прогресс по всем играм
game.html             плеер: iframe + реклама + аккаунт + учёт времени
games.json            реестр игр (единственное место, куда добавлять игру)
assets/config.js      ← правится под себя: Supabase, реклама, бренд
assets/host.js        мост портала: принимает вызовы игры
assets/ads.js         адаптер рекламы (stub / РСЯ / AdSense)
assets/db.js          Supabase-клиент, анонимные сессии, вход
assets/library.js     сбор прогресса игрока, уровни, форматирование
assets/catalog.js     каталог из базы (с откатом на games.json) и языки
sdk/playdrop-sdk.js   подключается ВНУТРЬ игры
server/schema.sql     таблицы, RLS и RPC для Supabase
server/translate/     Edge Function перевода на английский
server/yandex-userinfo/  Edge Function для входа через Яндекс (опционально)
tools/add-game.js     добавление многофайлового билда из командной строки
SETUP.md              подробная инструкция по запуску
games/<id>/           билды игр
```

## Запуск

Пошагово — в **SETUP.md**. Коротко:

1. `npx serve .` — площадка уже работает на localStorage, без бэкенда.
2. Supabase: выполнить `server/schema.sql`, включить анонимный вход, вписать ключи в `assets/config.js`.
3. Залить на хостинг (GitHub Pages / Railway).
4. Реклама и именованный вход — по желанию, позже.

## Авторизация

По умолчанию используется **анонимный вход**: сессия создаётся молча при первом заходе, прогресс сразу пишется на сервер, никаких форм и кнопок. Этого хватает для сейвов, рекордов, серии дней и профиля.

Именованный вход нужен только чтобы переносить прогресс между устройствами и показывать имя в таблице рекордов. Встроенного провайдера Яндекса у Supabase нет — он заводится через Custom OAuth Provider плюс маленькая функция-прослойка (`server/yandex-userinfo/`), подробности в SETUP.md. Пока `auth.provider: null` — кнопки входа не показываются вообще.

## Как подключить существующую игру

Игра под Yandex SDK — заменить одну строку:

```html
<!-- было -->
<script src="https://yandex.ru/games/sdk/v2"></script>
<!-- стало -->
<script src="/sdk/playdrop-sdk.js"></script>
```

Дальше весь код остаётся: `YaGames.init()`, `ysdk.adv.showRewardedVideo`, `player.setData`, лидерборды — всё перехватывается мостом и уходит в Supabase.

Новая игра — то же самое, только через `PlayDrop`:

```js
const player = await PlayDrop.getPlayer();
await player.setData({ level: 7 });
PlayDrop.adv.showRewardedVideo({ callbacks: { onRewarded: () => giveCoins(100) } });
PlayDrop.features.LoadingAPI.ready();   // убирает лоадер портала
```

Игра, открытая напрямую (не в iframe портала), автоматически падает в localStorage и не ломается.

## Реклама

`config.js → ads.provider`:

- `stub` — заглушка с таймером, для отладки;
- `yandex` — РСЯ. Нужен модерированный сайт с реальным трафиком и блок формата «Fullscreen». Раскомментировать скрипт `context.js` в `game.html`;
- `adsense` — если целишься на зарубежный трафик.

Rewarded в вебе честно отдаётся только через сеть, поддерживающую rewarded-формат. Пока сети нет — `stub` показывает таймер и всё равно выдаёт награду, механика игры отлаживается.

## Удержание: как это работает

**Полка «Продолжить»** на главной строится из `my_library()` — RPC собирает `game_saves`, `play_activity` и `scores` в один список, отсортированный по последнему запуску. Для гостя тот же список собирается из localStorage, так что полка появляется после первой же сессии, до всякой регистрации, и под ней висит подсказка про вход.

**Время в игре** считается в плеере: тик каждые 5 секунд, пауза на рекламе и при сворачивании вкладки, отправка на сервер раз в 30 секунд и при уходе со страницы. Накрутить время, оставив вкладку фоном, нельзя.

**Серия дней** обновляется той же `track_play()`: играл вчера — +1, пропустил день — сброс до 1. Рекорд серии хранится отдельно и не сгорает.

**Уровень** — минуты в играх плюс 20 XP за каждую освоенную игру; порог уровня растёт линейно (25 XP × номер уровня). Первый уровень берётся примерно за полчаса, дальше кривая замедляется. Правится в `library.js` → `xpFrom` и `levelFrom`.

**Место в таблице** показывается и на полке, и в профиле: «12-е место из 340» — конкретный повод вернуться и переиграть.

После первого выполнения `schema.sql` файл можно выполнить повторно — блок v2 идемпотентный, данные не теряются.

## Что стоит добавить дальше

- **Модерация чужих игр** — если открывать площадку для других разработчиков: таблица `games` в БД вместо `games.json` + статус `draft/review/live`.
- **Выплаты разработчикам** — доля от рекламы, самая тяжёлая часть юридически. На старте проще держать площадку только под свои игры.
- **Внутриигровые покупки** — `pay.purchase` сейчас бросает `PAYMENTS_NOT_CONFIGURED`. Подключается ЮKassa: создание платежа на бэкенде + вебхук, пишущий строку в `purchases`.
- **Ежедневная награда** за серию — самая дешёвая надстройка над готовым streak: на 3-й и 7-й день выдавать внутриигровую валюту через `player.setData`.
- **Пуш о сгорающей серии** — web push на 20:00, если сегодня ещё не играл. Работает сильнее любой подборки на главной.
- **Витрина**: подборки, счётчик онлайна, «сыграл 1 из 4 игр — попробуй остальные».
